# UMHackathon_BalaenaQuant

## Project Overview
BalaenaQuant is a backtesting and trading strategy evaluation framework designed to simulate trading strategies, manage client portfolios, and calculate relevant performance metrics. The framework supports various strategies, including Machine Learning-based approaches and traditional technical analysis, such as Moving Average crossovers.

## Directory Structure

### backtester
Contains the core components for data handling, strategy execution, portfolio management, and performance evaluation.
- data_handler.py: Responsible for retrieving data from APIs, preprocessing, performing feature engineering, and passing the prepared data to the backtesting engine.

- engine.py: The main backtesting engine that generates trading signals based on the chosen strategies, simulates trades with the portfolio, and computes performance metrics.

- metrics.py: Contains classes and functions to calculate key performance metrics, such as Sharpe ratio, Sortino ratio, maximum drawdown, and recovery period, from trading records.

- portfolio.py: Manages the client’s portfolio, simulates trade execution, and handles portfolio management in different market scenarios.

- utils.py: Contains utility functions and helper classes shared across the project.

### models
This directory stores the machine learning models used for generating predictions, such as buy or sell probabilities, for ML-based trading strategies.

### records
Stores historical trading records, enabling traceability and facilitating the evaluation and refinement of trading strategies.

### strategy
Contains the strategy framework and specific implementations of trading strategies.
- strategy_base.py: An abstract interface that defines the basic structure for different strategy classes.
- ml_strategy.py: Implements a machine learning-based strategy using probabilities generated by trained models.
- ma_crossover_strategy.py: Implements a traditional Moving Average crossover strategy, where trading signals are generated based on the intersection of short-term and long-term moving averages.
